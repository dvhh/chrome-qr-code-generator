# Simple Chrome QR Code generator Extension

![Wikipedia QR code entry](icon.png)

## Overview
Simple QR code generator for Chrome

## Installation
1. Open the [Extensions Page][(chrome://extensions)
2. Toggled `Developer mode` to `on`
3. Click the `Load unpacked` button
4. in the file browser, navigate and select the root folder of the extension
5. Click `Select Folder` (or `Open`)

The extension `Pure JS QR Generator 1.1` Should appear in the list of your Extension

## Usage
Click on the toolbar on the QR code button to generate a QR code for the current page, 
the generated image in the popup should be scannable by any smartphone generator
